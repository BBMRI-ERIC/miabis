# Definition

The Biobanking and Biomolecular entity, with its specific attributes, enables a generic service to be assigned to an organisation, while also allowing for the detailed description of contact information, service type, technology used, and access description.

| Attribute Code | Attribute Name | Description | Data Type | Allowed Values | Constraints | Cardinality |
| --- | --- | --- | --- | --- | --- | --- |
| MIABIS-SERVICE-01 | ID | ID of the biobanking an biomolecular service | string | | The ID must be given by the biobank, but its structure may be determined by decisions of the ecosystem the biobank is part of. | 1..1 |
| MIABIS-SERVICE-02 | Acronym | Short name in use for the biobanking and biomolecular service. If applicable. | string | | Short symbol in use for the service. Shouldn't be more than 12 characters. If applicable. | 0..1 |
| MIABIS-SERVICE-03 | Name | Name of the biobanking and biomolecular service (preferably in English). | string | | Defined by biobank staff. Shouldn't take more than 30 (40?) characters. | 1..1 |
| MIABIS-SERVICE-04 | URL | Complete http-address for the biobanking and biomolecular service | string | | Complete http-address for the service. If available. | 0..1 |
| MIABIS-SERVICE-05 | Description | Description of the biobanking and biomolecular service in English. | string | | Free text description of the service. Recommendation max. 2000 char. Important and interesting information about this particular service should be included. | 1..1 |
| MIABIS-SERVICE-06 | Contact information | Contact information for the contact person/person responsible of the biobanking and biomolecular service. | structured data | [Contact information](https://github.com/BBMRI-ERIC/miabis/blob/master/all%20structured%20data.md#contact-information) | | 0..1 |
| MIABIS-SERVICE-07 | Service type | One or more coded values that specify the type of service assigned by the biobank because of its scope. This is a planned process in which a service provider performs a task for a service consumer. | value set | [Service type](https://github.com/BBMRI-ERIC/miabis/blob/master/all%20lists.md#service-type) Sample reception, Sample processing, Sample storage, Sample quality control and report, Sample provision, Sample transport, Sample data management, Histology techniques, Derivative extraction, Genomics resource, Transcriptomics resource, Proteomics resource, Metabolomics resource, Multi-OMICs/Integrative analysis, Analytical biochemistry resource, Pharmacology resource, Microscopy imaging resource, Experimental pathology resource, Cell culture resource, Microbiology/Virology resource, Animal model resource, 3D model development resource, Big data management resource, Bioinformatics resource, Biostatistics resource, Study design, Study ELSI management, Study protocol development, Lab protocol training, Informed consent management, Industry collaboration, Other service type | | 1..n |
| MIABIS-SERVICE-08 | Technology | The technology applied in the service provision | structured data | [Technology](https://github.com/BBMRI-ERIC/miabis/blob/master/all%20structured%20data.md#technology) | | 0..n |
| MIABIS-SERVICE-09 | Access description | Description of the the service access policy | string | | | 0..1 |
